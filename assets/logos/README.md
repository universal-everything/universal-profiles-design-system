# Logos

This folder is intentionally empty of mark files.

No vector master of the UP! badge, the two-line "UNIVERSAL / PROFILES" wordmark, the periwinkle cube or the "Powered by LUKSO" lockup has been supplied to this repository; only rasters exist in the app bundle, the posters and a private brand board (OPEN-03). Recreating a mark from its description would produce a fake mark, which `../../brand/misuse.md` prohibits. The LUKSO and Universal Everything marks exist as vectors in the web product, but republishing them here needs trademark guidance first (OPEN-04).

The one place the cube (the UP! box) is visible in this repository is inside the twelve generated slide backgrounds under `../generated/backgrounds/slides-v2/`, where the generator rendered it from the owner's board reference at the owner's request (decision 0012, `../../decisions/0012-branded-slide-backgrounds.md`). Those files are scenes, not mark files: the mark on them is not licensed for extraction or standalone reuse, the reference stays unpublished, and nothing may be cropped out of them to serve as a logo. Official files still come only from the brand owner.

Until masters and a licence statement arrive:

- Product teams keep using the mark files already in their repositories.
- Marketing requests official files from the brand owner and follows `../../brand/lockups.md` for construction, colour variants and provisional clear space.
- Any file added here must be an official file supplied by the brand owner, with a `PROVENANCE.json` entry recording author, source, licence and the owner's authorization. A reconstruction is never admitted under any label (`../../decisions/0010-no-reconstruction-under-any-label.md`); the validator rejects an entry marked `reconstructed`.
