# 0005 LUKSO magenta reserved for network and LYX roles

Status: accepted
Date: 2026-09-14

## Context

Magenta `#FE005B` is the LUKSO mark, the LYX token colour and the mainnet signal in the app, and the foundation's decks use it with pale pink. Universal Profiles collateral uses periwinkle.

## Decision

`color.network.lukso-mainnet` is the only magenta token. It is used for the LUKSO mark, the LYX logo and network dots, never as a Universal Profiles accent, badge colour or background.

## Consequences

Clear separation between the parent brand and the product; the misnamed mobile logo component is renamed during migration.

## Evidence

SRC-MOBILE-APP network colours; SRC-WEB-APP marks; SRC-BRAND-DNA-2024 theme colours.
